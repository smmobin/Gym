# TODOهای باز مدل داده (نسخهٔ اول)

مواردی که جدول/فیلد دارند ولی منطق کامل محصول هنوز مرحلهٔ بعد است:

| موضوع | وضعیت مدل | کار بعدی |
|--------|-----------|----------|
| قفل پروندهٔ عضو (۵ دقیقه) | جدول جدا نیست | **هنوز برای PATCH عضو نیامده** — برش لیست/ثبت بدون قفل است |
| خروج خودکار پایان روز | فیلد `day_end_time` در `gym_settings` | job/ کرون یا چک هنگام ورود |
| شمارهٔ رسید خودکار | فیلد `receipt_number` یکتا | تولید ترتیبی در سرویس پرداخت |
| یکتایی واگذاری فعال کمد | تاریخچه با `released_at` | قید جزئی Postgres یا چک سرویس |
| چند مربی فعال هم‌زمان | ردیف‌های `ended_at IS NULL` | ایندکس جزئی unique بعداً |
| مصرف جلسه برای غیبت کلاس | فیلد `sessions_remaining` | منطق حضور/کلاس |

این فایل فقط یادآور است؛ migration اول را بلاک نمی‌کند.
