## مرحلهٔ بعد

1. **کار دستی صاحب (لوکال):** اگر هنوز مدیر واقعی نداری → `bootstrap_manager` با موبایل/رمز خودت → از پنل `#staff` منشی بساز و از `#plans` طرح‌ها را بگذار. مسیر خالی: wipe (فقط dev) → bootstrap → پنل.
2. **قبل از دادهٔ زنده:** یک‌بار مسیر بکاپ/restore را طبق `docs/guides/backup.md` تمرین کن.
3. **دیپلوی production** وقتی آماده بودی طبق `docs/guides/deploy.md` (کلید درگاه/پیامک فقط در env سرور).
4. **برش کدنویسی اختیاری** فقط با درخواست تو (مثلاً صف/زمان‌بندی تمدید، یا چیز دیگر) — مدیر محصول همان‌وقت پرامپت کامل می‌نویسد.
