# وضعیت نقشهٔ راه — GYM CONTROL

**آخرین به‌روزرسانی:** ۱۴۰۴-۰۷-۲۷ (2026-10-19) — برش تنظیمات/اعلان/پیامک تأیید و پیاده شد  
**نقش:** سند زندهٔ مدیر محصول — بعد از هر مرحلهٔ انجام‌شده باید عوض شود.

## الان کجاییم؟

کارکنان روی لوکال تقریباً کامل‌اند، به‌علاوهٔ فرم آزمایشی، گزارش مدیر، **تنظیمات باشگاه**، **اعلان داخل‌برنامه**، و **placeholder پیامک/درگاه**.  
هنوز باز: پنل ورزشکار، دیپلوی واقعی با HTTPS و بکاپ.

## انجام شده

- اسکلت، مدل‌ها، migration، seed، قوانین کسب‌وکار
- auth، اعضا، حضور، مالی میز، کلاس، کمد، مربی/برنامه، قفل پرونده
- گزارش مدیر `/reports`
- آزمایشی عمومی + صف + مهمان روزانه
- تنظیمات `/settings` + اعلان زنگوله + `/sms-templates`

## الان نکن

- لاگین ورزشکار، پیامک واقعی، درگاه آنلاین واقعی
- HTML ریشه به‌عنوان محصول واقعی
- خرید SDK پیامک / کلید در گیت

## مرحلهٔ بعد (همین حالا)

**یک جمله:** پنل ورزشکار (لاگین ورزشکار) وقتی کارکنان پایدار شد — یا آماده‌سازی HTTPS/بکاپ قبل از دادهٔ واقعی.

| به زبان ساده | یعنی چه |
|--------------|---------|
| ورزشکار | ورود با موبایل، دیدن اشتراک/بدهی خودش، درخواست تمدید واقعی |
| استقرار | هاست واقعی، بکاپ Postgres، نه فقط GitHub Pages |

## حفره‌ها

- GitHub Pages ≠ محصول واقعی
- قفل روی UI ویرایش اعضا هنوز نیست
- درخواست تمدید واقعی وابسته به لاگین ورزشکار است (فعلاً seed/placeholder)
