## مرحلهٔ بعد

1. صاحب: پرامپت Logging را به **چت سازنده** بدهد (متن کامل در `next-coding-prompt.md`)  
2. بعد از سبز شدن تست: مسیر `backend/logs/` را برای دیباگ خودش نگه دارد؛ در پنل فقط `#activity`  
3. سپس Slice J یا سخت‌کردن دیپلوی HTTPS  

## تصمیم محصولی قفل‌شده (لاگ)

- لاگ کامل فایل = فقط سازنده روی دیسک (`backend/logs/`) — **بدون URL عمومی**  
- پنل مدیر = زیرمجموعهٔ فعالیت (ورود/خروج، پول/طرح/تنظیمات، خلاصهٔ خطای مهم) + خروجی `.log` بازه  
- رمز / API key / OTP کامل در هیچ فایلی ذخیره نمی‌شود؛ PII محدود فقط در `sensitive.log`
