## تصمیم صاحب (این برش)

1. در لیست انتخاب عضو برای واگذاری کمد، اگر عضو کمد فعال دارد مشخص شود.
2. تا آزادسازی، دوباره برای کمد جدید انتخاب نشود (دیده بشود، نه مخفی).
3. قانون سرور (حداکثر یک کمد فعال) از قبل هست؛ مشکل فقط شفافیت UI است.
