# وضعیت نقشهٔ راه — GYM CONTROL

**آخرین به‌روزرسانی:** ۱۴۰۴-۰۷-۲۷ (2026-10-19) — لاگین ورزشکار فعال شد  
**نقش:** سند زندهٔ مدیر محصول — بعد از هر مرحلهٔ انجام‌شده باید عوض شود.

## الان کجاییم؟

کارکنان + **پنل ورزشکار** روی لوکال: ورود با موبایل+رمز، فقط دادهٔ خودش، درخواست تمدید → اعلان میز.  
هنوز باز: دیپلوی واقعی (HTTPS + بکاپ)، پیامک/درگاه واقعی، رزرو کلاس توسط ورزشکار.

## انجام شده

- اسکلت، مدل‌ها، migration، seed، قوانین کسب‌وکار
- auth کارکنان، اعضا، حضور، مالی میز، کلاس، کمد، مربی/برنامه، قفل پرونده
- گزارش مدیر، آزمایشی/مهمان، تنظیمات، اعلان desk، placeholder پیامک
- **لاگین ورزشکار** (`/athlete`) — cookie جدا، رمز توسط desk

## الان نکن

- پیامک واقعی / OTP / درگاه آنلاین واقعی
- HTML ریشه به‌عنوان محصول واقعی
- خرید SDK و کلید در گیت

## مرحلهٔ بعد (همین حالا)

**یک جمله:** آماده‌سازی استقرار واقعی (هاست + HTTPS + بکاپ Postgres و تست restore).

| به زبان ساده | یعنی چه |
|--------------|---------|
| هاست | مثلاً لیارا / مشابه — نه فقط GitHub Pages |
| بکاپ | هفتگی دستی جدا از لپ‌تاپ + یک‌بار restore |
| حفرهٔ کوچک | قفل روی UI ویرایش اعضا |

## بعد از آن (صف)

1. اختیاری: رزرو کلاس توسط ورزشکار
2. اتصال واقعی پیامک / درگاه وقتی آماده شد
