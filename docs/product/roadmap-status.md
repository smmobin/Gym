## مرحلهٔ بعد

1. سخت‌کردن دیپلوی HTTPS / هاست واقعی  
2. یا صف محصول بعدی که مدیر محصول بنویسد  

## تصمیم محصولی قفل‌شده (لاگ)

- پنل مدیر `#activity` = **فقط خلاصه** فعالیت باشگاه — stack/خام فایل نه  
- لاگ کامل سازنده = پوشهٔ `backend/logs/` + UI `/dev-logs/` فقط با توکن env (نه منوی عادی منشی/مدیر)  
- در `APP_ENV` production-like این UI/API همیشه ۴۰۴ است؛ روی سرور واقعی فایل یا SSH  
- بدون URL عمومی باز روی اینترنت  
- رمز / API key / OTP کامل در هیچ فایلی ذخیره نمی‌شود  
- `request_id` ستون واقعی `audit_logs` است
