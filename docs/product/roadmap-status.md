## تصمیم / مسیر پیامک واقعی

1. برای تست واقعی **همین هفته:** کاوه‌نگار (هدیهٔ آزمایش API معمولاً بعد از ثبت‌نام).  
2. کد را عوض نکن مگر کلید کار نکرد یا provider دیگری خواستی.  
3. کلید را فقط در `backend/.env` بگذار؛ commit نکن.

## مرحلهٔ بعد

1. صاحب: ثبت‌نام کاوه‌نگار → API KEY → `.env` → ری‌استارت → تست `#sms` و OTP  
2. اگر OK شد: در چت مدیر محصول بگو «پیامک واقعی OK» تا roadmap قفل شود  
3. اگر پنل دیگری خواستی: پرامپت adapter از مدیر محصول  
4. سپس Slice J یا دیپلوی HTTPS
