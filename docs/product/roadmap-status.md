- لاگ کامل فایل = فقط سازنده روی دیسک (`backend/logs/`) — **بدون URL عمومی**

- رمز / API key / OTP کامل در هیچ فایلی ذخیره نمی‌شود؛ موبایل کامل فقط در `sensitive.log`  
- `request_id` ستون واقعی `audit_logs` است (migration `k1e2f3a4b5c6`)
