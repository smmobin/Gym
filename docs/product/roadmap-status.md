# وضعیت نقشهٔ راه — GYM CONTROL

**آخرین به‌روزرسانی:** ۱۴۰۴-۰۷-۲۵ (2026-10-17) — مدیر محصول تأیید کرد: برش حضور انجام شد  
**نقش:** سند زندهٔ مدیر محصول — بعد از هر مرحلهٔ انجام‌شده باید عوض شود.

## الان کجاییم؟

Auth + اعضا + **حضور ورود/خروج** آماده‌اند (`/attendance`، قوانین منقضی/بدهی/ورود دوم/جلسه؛ تست حضور سبز).  
**هنوز نیست:** تمدید و پرداخت عملیاتی، گزارش مالی کامل، کلاس/کمد روزمره.

## انجام شده

- اسکلت، مدل‌ها، migration، seed، قوانین کسب‌وکار
- auth کارکنان + صفحهٔ `/login`
- اعضا: لیست/ثبت/آرشیو + `/members`
- حضور: check-in/out + `/attendance` (خروج خودکار روی مسیر API، نه کرون)

## الان نکن

- لاگین ورزشکار، پیامک واقعی، درگاه آنلاین واقعی
- HTML ریشه به‌عنوان محصول واقعی
- ساخت هم‌زمان کلاس+کمد+گزارش کامل مدیر در همین برش
- ویرایش مبلغ پرداخت ثبت‌شده (ممنوع — فقط برگشت + پرداخت جدید)

## مرحلهٔ بعد (همین حالا)

**یک جمله:** تمدید اشتراک + ثبت پرداخت (ناقص مجاز) + رسید خودکار + audit مالی/عضویت.

| به زبان ساده | یعنی چه |
|--------------|---------|
| تمدید | ردیف عضویت جدید از پایان اشتراک فعلی (روز نسوزد) |
| پرداخت | ثبت پول نقد/کارت/انتقال؛ آنلاین فقط در لیست بدون درگاه |
| audit | چه کسی چه زمانی تمدید/پرداخت/برگشت زد |
