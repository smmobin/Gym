# وضعیت نقشهٔ راه — GYM CONTROL

**آخرین به‌روزرسانی:** ۱۴۰۴-۰۷-۲۴ (2026-10-17) — پس از برش لیست/ثبت عضو  
**نقش:** سند زندهٔ مدیر محصول — بعد از هر مرحلهٔ انجام‌شده باید عوض شود.

## الان کجاییم؟

Auth کارکنان و **برش اعضا** (API + UI پشت لاگین: لیست، ثبت، آرشیو؛ مربی فقط شاگردها) آماده‌اند.  
**هنوز نیست:** حضور، تمدید/پرداخت، پنل کامل نقش‌ها.

## انجام شده

- اسکلت فرانت/بک، مدل‌ها، migration، seed
- auth کارکنان (cookie نشست، نقش سمت سرور، صفحهٔ `/login`)
- **اعضا:** `GET/POST/PATCH` + آرشیو نرم + صفحهٔ `/members`

## الان نکن

- لاگین ورزشکار
- عضویت/پرداخت/حضور در همین لحظه مگر برش جدا
- پیامک / درگاه / HTML ریشه به‌عنوان محصول واقعی

## مرحلهٔ بعد (همین حالا)

**یک جمله:** حضور ورود/خروج روزانهٔ منشی (روی عضو موجود، با قوانین اشتراک معتبر/منقضی).
