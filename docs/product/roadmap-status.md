# وضعیت نقشهٔ راه — GYM CONTROL

**آخرین به‌روزرسانی:** ۱۴۰۴-۰۷-۲۷ (2026-10-19) — برش مهمان/آزمایشی تأیید شد؛ مرحلهٔ بعد تنظیمات/اعلان  
**نقش:** سند زندهٔ مدیر محصول — بعد از هر مرحلهٔ انجام‌شده باید عوض شود.

## الان کجاییم؟

کارکنان روی لوکال تقریباً کامل‌اند، به‌علاوهٔ **فرم آزمایشی** (`/trial`)، صف (`/trial-leads`)، مهمان روزانه (`/guests`).  
هنوز باز: تنظیمات باشگاه در UI، اعلان داخل‌برنامه، placeholder پیامک، پنل ورزشکار، دیپلوی واقعی.

## انجام شده

- اسکلت، مدل‌ها، migration، seed، قوانین کسب‌وکار
- auth، اعضا، حضور، مالی میز، کلاس، کمد، مربی/برنامه، قفل پرونده
- گزارش مدیر `/reports`
- آزمایشی عمومی + صف + مهمان روزانه

## الان نکن

- لاگین ورزشکار، پیامک واقعی، درگاه آنلاین واقعی
- HTML ریشه به‌عنوان محصول واقعی
- خرید SDK پیامک / کلید در گیت
- ساخت هم‌زمان پنل ورزشکار کامل در همین برش

## مرحلهٔ بعد (همین حالا)

**یک جمله:** تنظیمات باشگاه + اعلان داخل‌برنامه + placeholder پیامک/درگاه.

| به زبان ساده | یعنی چه |
|--------------|---------|
| تنظیمات | نام/تلفن/ساعت پایان روز/هشدار انقضا/سقف freeze |
| اعلان | زنگوله برای انقضا، بدهی، فرم آزمایشی |
| پیامک | قالب + دکمهٔ مرده |
| UI | `/settings` و اعلان در شل |

## بعد از آن (صف)

1. پنل ورزشکار (لاگین ورزشکار) وقتی کارکنان پایدار شد
2. HTTPS و بکاپ قبل از دادهٔ واقعی (هاست واقعی، نه فقط GitHub Pages)

## حفره‌ها

- GitHub Pages ≠ محصول واقعی
- مدل اعلان هنوز نیست
- API/UI تنظیمات هنوز نیست (جدول `gym_settings` هست)
- قفل روی UI ویرایش اعضا هنوز نیست
