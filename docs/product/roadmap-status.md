**آخرین به‌روزرسانی:** ۱۴۰۴-۰۸-۰۹ (2026-10-31) — صف: نشان «کمد فعال» در picker واگذاری  
**نقش:** سند زندهٔ مدیر محصول — بعد از هر مرحلهٔ انجام‌شده باید عوض شود.

## الان کجاییم؟

| برش | وضعیت |
|-----|--------|
| A…H | انجام‌شده |
| Idle / اعلان / toastهای مرتبط | در کد |
| حذف toast لاگ شمارش/بارگذاری (A1–A8) | صف قبلی؛ اگر سازنده نزده بعداً |
| **Picker کمد: «کمد دارد (کد)» + متن «شامل کمد» به‌جای «واجد کمد»** | **صف فوری / پرامپت آماده** |
| آیکون سایدبار + حذف mount تنظیمات منشی | عقب‌افتاده (پرامپت قبلی موجود بود) |
| پیامک آزمایشی (`SMS_PROVIDER=fake`) | عقب‌افتاده |
| J — مدیر/منشی هم‌زمان مربی | صف بعدی محصول بزرگ |

## تصمیم صاحب (این برش)

1. در لیست انتخاب عضو برای واگذاری کمد، اگر عضو کمد فعال دارد مشخص شود.
2. تا آزادسازی، دوباره برای کمد جدید انتخاب نشود (دیده بشود، نه مخفی).
3. برچسب عضویت «واجد کمد» → «شامل کمد» (زبان ساده‌تر برای منشی؛ هم‌معنی با طرح includes_locker).
4. قانون سرور (حداکثر یک کمد فعال) از قبل هست؛ مشکل اصلی شفافیت UI است.
