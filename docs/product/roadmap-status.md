# وضعیت نقشهٔ راه — GYM CONTROL

**آخرین به‌روزرسانی:** ۱۴۰۴-۰۸-۰۷ (2026-10-29) — صف: اعلان ورزشکار (خواندن همه + رزرو کلاس) و حذف toast شمارش کلاس  
**نقش:** سند زندهٔ مدیر محصول — بعد از هر مرحلهٔ انجام‌شده باید عوض شود.

## الان کجاییم؟

| برش | وضعیت |
|-----|--------|
| A…H | انجام‌شده |
| Idle ۲۵ دقیقه / قفل فونت ریشه | در کد |

| J — مدیر/منشی هم‌زمان مربی | صف بعدی محصول بزرگ |

## تصمیم صاحب (این برش)

1. بالای لیست اعلان ورزشکار: گزینهٔ خواندن همه  
2. وقتی کلاس به ورزشکار تعلق گرفت (رزرو موفق) → اعلان داخل‌برنامه برای همان ورزشکار  
3. toast سبز تکراری «۷ کلاس» در بخش کلاس‌های منشی حذف/ساکت شود (مخصوصاً با auto-refresh)
