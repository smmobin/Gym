## الان کجاییم؟

Auth کارکنان + **لیست/ثبت/آرشیو عضو** (API و UI پشت لاگین؛ مربی فقط شاگردها) آماده‌اند. تست `test_members` سبز تأیید شد.

## انجام شده

- اسکلت، مدل‌ها، migration، seed، قوانین کسب‌وکار
- auth کارکنان (cookie، نقش، `/login`)
- اعضا: `GET/POST/PATCH` + آرشیو نرم + `/members`

## الان نکن

- لاگین ورزشکار
- تمدید/پرداخت/کلاس/کمد قبل از اتمام برش حضور (مگر وابستگی خیلی کوچک داخل حضور)
- پیامک / درگاه / HTML ریشه به‌عنوان محصول واقعی
- پنل کامل همهٔ نقش‌ها در یک برش

## مرحلهٔ بعد (همین حالا)

**یک جمله:** حضور روزانه — ورود و خروج روی عضو موجود، با قوانین اشتراک معتبر/منقضی و بدهی.

| به زبان ساده | یعنی چه |
|--------------|---------|
| ورود (check-in) | عضو وارد سالن/کلاس/جلسه مربی شد |
| خروج (check-out) | زمان خروج ثبت شود |
| اشتراک منقضی | ورود ممنوع تا تمدید |
| بدهی با اشتراک معتبر | ورود مجاز + هشدار به منشی |
