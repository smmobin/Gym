**آخرین به‌روزرسانی:** ۱۴۰۴-۰۷-۲۷ (2026-10-19) — پنل ورزشکار تأیید شد؛ مرحلهٔ بعد استقرار  
**نقش:** سند زندهٔ مدیر محصول — بعد از هر مرحلهٔ انجام‌شده باید عوض شود.

## الان کجاییم؟

**نسخهٔ عملیاتی روی لوکال برای کارکنان + ورزشکار تقریباً کامل است.**  
گام بعدی دیگر فیچر میز نیست؛ **آماده‌سازی استقرار واقعی** (هاست، HTTPS، بکاپ/restore) است تا دادهٔ واقعی وارد شود.

## انجام شده (محصول)

- اسکلت، مدل‌ها، migration، seed، قوانین کسب‌وکار
- کارکنان: auth، اعضا، حضور، مالی، کلاس، کمد، مربی/برنامه، قفل پرونده، گزارش، آزمایشی/مهمان، تنظیمات، اعلان، placeholder پیامک
- ورزشکار: `/athlete/login` + داشبورد خود + درخواست تمدید → اعلان desk

## الان نکن

- وارد کردن دادهٔ واقعی عضو قبل از بکاپ+HTTPS
- پیامک/درگاه واقعی بدون طراحی جدا
- seed پاک‌کننده روی دیتابیس production
- فرض کردن GitHub Pages به‌عنوان سامانهٔ واقعی

## مرحلهٔ بعد (همین حالا)
