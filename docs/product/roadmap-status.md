## مرحلهٔ بعد (همین حالا)

**یک جمله:** ورود کارکنان واقعی (موبایل + رمز، نقش روی سرور، نشست امن) تا بعد بتوان برش «لیست/ثبت عضو» را امن ساخت.

| چیست به زبان ساده | یعنی چه | در باشگاه به چه درد می‌خورد؟ |
|-------------------|---------|------------------------------|
| auth / ورود | تشخیص کی وارد شده | منشی و مدیر جدا شناخته شوند |
| نشست (session) | بعد از ورود، سرور بداند هنوز همان نفر است | بدون باز کردن دوبارهٔ رمز برای هر کلیک |
| نقش سمت سرور | API دسترسی را چک کند | قایم‌کردن دکمه در UI امنیت نیست |
