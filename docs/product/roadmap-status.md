## الان کجاییم؟

Auth + اعضا + حضور + **تمدید/پرداخت/برگشت/رسید/audit** آماده‌اند (`/billing`).  
**هنوز نیست:** گزارش مالی کامل مدیر، کلاس/کمد روزمره، قفل پرونده.

## انجام شده

- اسکلت، مدل‌ها، migration، seed، قوانین کسب‌وکار
- auth کارکنان + صفحهٔ `/login`
- اعضا: لیست/ثبت/آرشیو + `/members`
- حضور: check-in/out + `/attendance`
- مالی: طرح‌ها، تمدید، پرداخت ناقص، refund، رسید `R-…`، audit + `/billing`

## الان نکن

- لاگین ورزشکار، پیامک واقعی، درگاه آنلاین واقعی
- HTML ریشه به‌عنوان محصول واقعی
- ساخت هم‌زمان کلاس+کمد+گزارش کامل مدیر در همین برش
- ویرایش مبلغ پرداخت ثبت‌شده (ممنوع — فقط برگشت + پرداخت جدید)

## مرحلهٔ بعد (همین حالا)

**یک جمله:** کلاس گروهی یا کمد یا واگذاری مربی — هر کدام ارزش روزانهٔ بیشتری دارد اول.

| به زبان ساده | یعنی چه |

| مربی | شاگرد ↔ مربی و محدودیت حضور |
