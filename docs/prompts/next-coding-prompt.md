# پرامپت مرحلهٔ بعد — برای چت سازنده (Agent)

آخرین به‌روزرسانی: ۱۴۰۴-۰۷-۲۷ (مدیر محصول — پس از برش استقرار/بکاپ)  
مرحله: اختیاری محصول بعدی (freeze عضویت) یا کمک دیپلوی واقعی روی اکانت صاحب

اگر صاحب هنوز دیپلوی نکرده: اول [deploy.md](../guides/deploy.md) و [backup.md](../guides/backup.md) را با هم اجرا کند (credential در گیت نرود).

اگر فیچر محصول می‌خواهد، بلاک زیر را برای **freeze عضویت** کپی کند.

---

```text
# نقش
تو Agent سازندهٔ GYM CONTROL هستی. docs را از docs/README.md بخوان.
منبع حقیقت رفتار: docs/product/business-rules.md (بخش freeze).
UI فارسی RTL. کار فقط در frontend/ + backend/. رمز و .env در گیت نرود.

# هدف
پیاده‌سازی freeze عضویت طبق قوانین کسب‌وکار: سقف روز سالانه از gym_settings، audit، تست سبز، seed نمونه، بدون درگاه/پیامک.

# خارج از محدوده
رزرو کلاس ورزشکار؛ پیامک/درگاه واقعی؛ دیپلوی با credential صاحب مگر صریحاً بدهد.
```
