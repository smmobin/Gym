## هدف
الان «لوگو» فقط یک `.brand-mark` مربعی با گرادیان CSS است (بدون فایل تصویر). یک **لوگوی برند واقعی** برای محصول بساز و در لندینگ + پنل‌ها (و در صورت نیاز favicon) وصل کن تا هویت بصری GYM CONTROL مشخص شود.

## بریف برند (اجباری)
- نام محصول: **GYM CONTROL**
- حس: باشگاه مدرن، مرتب، حرفه‌ای — تم **Ocean Dark** (آبی/فیروزه‌ای تیره، نه بنفش AI-generic، نه کرم+سریس)
- لوگو باید در پس‌زمینهٔ تیره خوانا باشد
- ترجیح ساختار:
  1) **Mark** (نماد مربعی/rounded ~36–64px) مناسب جای `.brand-mark`
  2) اختیاری: نسخهٔ horizontal با wordmark اگر جنریت تمیز از آب درآمد؛ اگر متن روی تصویر ناخوانا شد → فقط mark تصویری + همان متن HTML فعلی (`GYM CONTROL` / زیرعنوان پنل)
- نماد پیشنهادی مفهومی (یکی را خوب اجرا کن، شلوغ نکن): حرف G ساده، یا دمبل مینیمال، یا سپر/کنترل ظریف — outline تمیز، نه عکس واقع‌گرایانه شلوغ
- بدون عکس استوک آدم، بدون Perso واقعی، بدون واترامارک، بدون متن ریز ناخوانا روی PNG

## داخل محدوده

### ۱) تولید دارایی
- با ابزار تصویر موجود (GenerateImage یا SVG دستی اگر تمیزتر است) حداقل:
  - `frontend/public/images/brand/logo-mark.png` (یا `.svg` اگر کیفیت بهتر) — آیکون mark
  - در صورت کیفیت خوب: `logo-horizontal.png` برای هدر لندینگ
  - `favicon.png` یا `.ico` / apple-touch در صورت ساده بودن
- اگر SVG دستی Ocean-aligned تمیزتر از AI raster است، SVG را ترجیح بده (مقیاس‌پذیر، سبک).

### ۲) اتصال UI (محصول واقعی = `frontend/`)
- لندینگ `frontend/index.html` و هر `.site-brand` / `.brand-mark`
- پنل‌ها: manager / receptionist / trainer / athlete (و در صورت وجود login) — جایی که `<span class="brand-mark"></span>` هست
- CSS: `.brand-mark` را از «فقط گرادیان خالی» به نمایش لوگو ارتقا بده (مثلاً `background-image` یا `<img alt="">` داخل brand؛ `alt` مناسب مثل «GYM CONTROL»)
- تم روشن/تاریک: لوگو روی هر دو خوانا بماند (در صورت نیاز نسخهٔ تک‌رنگ `currentColor` یا دو فایل)
- HTML ریشه / GitHub Pages فقط اگر الگوی برند آنجا کپی مرده است و طبق قوانین پروژه مجاز است؛ اولویت با `frontend/`

### ۳) کیفیت
- رتینا: اندازهٔ کافی (مثلاً mark 128–256px منبع)
- حجم معقول
- یکدست در همهٔ پنل‌ها

### ۴) docs کوتاه
- یک خط در getting-started یا project-rules که مسیر فایل لوگو کجاست (اختیاری ولی مفید)
