# پرامپت بعدی برای Agent سازنده

**وضعیت:** برش‌های A (ورود یکپارچه + مربی)، B (درگاه)، C (پیامک) **انجام شده‌اند.**  
صف کدنویسی اجباری خالی است. اگر باگ یا برش جدید خواستی، از مدیر محصول پرامپت تازه بگیر.

---

## یادداشت (پرامپت C — آرشیو)

پیامک واقعی با کاوه‌نگار + env پیاده شد:

- `SMS_PROVIDER=none|kavenegar` ، `SMS_API_KEY` ، `SMS_SENDER`
- `GET /api/v1/sms/status` ، `POST /api/v1/sms/send` (مدیر/منشی)
- بدون OTP؛ وقتی خاموش → UI «هنوز آماده نیست»
