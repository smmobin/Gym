پیشنهادهای لوگوی برند

هنوز هیچ‌کدام لوگوی نهایی سایت نیستند. یکی را انتخاب کن (مثلاً بگو «A» یا «دمبل») تا همان را به‌عنوان لوگو اصلی وصل کنم. چیدمان منو از قبل برای لوگو-alone (بدون متن کنارش) آماده شده است.

A — مونوگرام GC

حروف G و C درهم؛ حس برند نرم‌افزاری.

a-monogram-gc

B — دمبل مینیمال

نماد ورزشی ساده؛ خوانا در اندازهٔ کوچک.

b-dumbbell

C — سپر / کنترل

حس اعتماد و مدیریت باشگاه.

c-shield

D — افقی با wordmark (AI)

مناسب هدر؛ اگر متن داخل تصویر ناخوانا بود از F استفاده کن.

d-horizontal

E — حلقه + G (SVG)

تمیز، مقیاس‌پذیر، هم‌رنگ Ocean.

e-ring-g

F — افقی SVG

مارک + متن GYM / CONTROL؛ مناسب منوی لندینگ بدون متن HTML جدا.

f-horizontal
